## Guía de Configuración y Ejecución

### 1. Instalación de Dependencias
Asegúrate de tener [Node.js](https://nodejs.org/) instalado. Luego, ejecuta:
```bash
npm install
```

### 2. Configurar variables de entorno
Crea un archivo `.env` en la raíz del proyecto y completa los valores:
```env
NEXT_PUBLIC_SUPABASE_URL=tu_url_de_supabase
NEXT_PUBLIC_SUPABASE_ANON_KEY=tu_anon_key_de_supabase
DATABASE_URL=tu_url_de_base_de_datos_postgresql
DIRECT_URL=tu_url_directa_de_base_de_datos
```

### 3. Inicializar la base de datos
Debes sincronizar tu esquema de Prisma con Supabase:
```bash
# Genera el cliente de Prisma
npm run db:generate

# Aplica el schema a la base de datos
npm run db:push
```

### 4. Ejecutar el Servidor de Desarrollo
Una vez configurado todo, inicia el backend:
```bash
npm run dev
```
El servidor estará disponible en `http://localhost:3000`.

## Scripts Disponibles
- `npm run dev`: Inicia el servidor de desarrollo.
- `npm run db:push`: Aplica cambios del esquema a la base de datos.
- `npm run db:generate`: Regenera el cliente de Prisma.
- `npm run db:studio`: Abre una interfaz visual para ver los datos.
